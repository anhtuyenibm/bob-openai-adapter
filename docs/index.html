THE CHALLENGE

Switching between APIs is tedious

You have code using OpenAI's API. You want to try Bob Shell. Rewriting the integration layer takes time and introduces bugs.

THE SOLUTION

Change two lines, keep everything else

The adapter mimics OpenAI's interface. Your existing code works with Bob - just swap the import and client initialization.

See it in action

# Before - using OpenAI
from openai import OpenAI
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# After - using IBM Bob Shell
from bob_openai_adapter import BobOpenAI as OpenAI
client = OpenAI(api_key=os.getenv("BOBSHELL_API_KEY"))

# Everything else stays the same
response = client.chat.completions.create(
    model="bob",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is Python?"}
    ]
)

print(response.choices[0].message.content)

How it works

1

Install

Copy the adapter file to your project. No pip dependencies - uses only Python standard library.

2

Import

Replace your OpenAI import with the Bob adapter. The interface is identical.

3

Configure

Set timeout, retries, and Bob-specific options like chat_mode and approval_mode.

4

Run

Your code calls IBM Bob Shell through the adapter. Messages are formatted, Bob executes, responses are wrapped.

5

Iterate

Switch between OpenAI and IBM Bob by changing one line. Test both, compare results, choose what works.
